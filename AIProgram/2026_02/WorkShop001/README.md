# Time Extraction

A model for extracting time form a Football (Soccer) Game frame.

## Concepts

### LVM (Large Vision Model)

1. Use ChatGPT / Gemini + Structured Response.
2. Use QWEN (`Qwen3-VL-4B`) / Gemma. Local model.

### Text Detection + OCR

 - [docTR](https://github.com/mindee/doctr) - Document Text Recognition.
 - [CRAFT](https://github.com/clovaai/CRAFT-pytorch) - Character Region Awareness for Text Detection.
 - [EasyOCR](https://github.com/JaidedAI/EasyOCR).
 - [PARSeq](https://github.com/baudm/parseq) - Scene Text Recognition with Permuted Autoregressive Sequence Models (See https://huggingface.co/spaces/baudm/PARSeq-OCR).
